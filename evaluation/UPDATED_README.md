# Updated deletion-audit prototype

This package includes a replacement evaluator (`src/case_evaluator.py`) and a new multi-format reader (`src/unified_evidence.py`). The original submission generator is preserved and produces 518 rows in `dataset/output.csv`.

## Run

```bash
PYTHONPATH=src python evaluation/improved_sample_check.py
PYTHONPATH=src python src/submission_generator.py
```

## Limitations — read before submitting

This is a **prototype, not a verified correct solution**. It reads SQL, JSON, structured logs, and handover TXT evidence and tracks timestamps, but **does not extract facts from PNG screenshots or PDF documents**. It cannot reliably associate a resource with a user once all identifiers are removed, and it may miss explicit absence confirmations, historical identifiers, or retained-record constraints. Some activity log outcomes are not yet reconciled with subsequent observations. In particular, a missing resource is **not** automatically considered deleted. `INCOMPLETE` cases with no steps are unresolved, not fully audited.

The included `dataset/output.csv` is generated by the prototype and passes basic output schema checks, **not the challenge's hidden correctness tests**. Inspect the sample-check results before using it for submission.
